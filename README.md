The funniest last words a phone says at 1% battery: **"Stop shaking me. It never helped, and now it just feels rude."** — the dying phone has feelings about how it is treated, and the punch lands on the very last beat.

## Run it

```sh
node main.ts
```

The program writes the line to `/output/entry.txt` (1–199 characters, UTF-8, single line, no trailing newline). Deterministic: the same bytes on every run. Node standard library only, no network.
